# Balanced factorial ratios inherit a cubic tower

**Status:** complete deduction from the classical
Ljunggren--Jacobsthal binomial congruence; exact checks supplied.  The
deduction is broad, but it is not presented as a new supercongruence
mechanism.

## 1. The closure theorem

Let $c_1,\ldots,c_M$ be integers satisfying the balance condition

```math
\sum_{m=1}^M m c_m=0,
```

and define the rational factorial ratio

```math
F(N)=\prod_{m=1}^M ((mN)!)^{c_m}.
\tag{1}
```

Assume that $F(N)$ is $p$-integral for every $N\geq1$.  Then, for
every prime $p\geq5$ and all positive integers $n,r$,

```math
\boxed{
F(np^r)\equiv F(np^{r-1})\pmod {p^{3r}}.
}
\tag{2}
```

If $F(N)$ is an integer for every $N$, the integrality hypothesis is of
course automatic for every prime.

### Proof

Put

```math
E_j=\sum_{m=j}^M c_m \qquad (2\leq j\leq M).
```

The elementary telescoping identity

```math
\delta_m-m\delta_1
=\sum_{j=2}^m(\delta_j-\delta_{j-1}-\delta_1)
```

in the free abelian group generated by factorial symbols, together with the
balance condition, gives the exact factorization

```math
F(N)=\prod_{j=2}^M \binom{jN}{N}^{E_j}.
\tag{3}
```

Negative exponents in (3) are allowed.  Each adjacent scaling quotient

```math
Q_j=
\frac{\binom{jnp^r}{np^r}}
     {\binom{jnp^{r-1}}{np^{r-1}}}
```

is a $p$-adic unit and, by the classical Ljunggren--Jacobsthal
congruence,

```math
Q_j\equiv1\pmod {p^{3r}}
\qquad p\geq5.
```

Consequently

```math
\frac{F(np^r)}{F(np^{r-1})}
=\prod_{j=2}^M Q_j^{E_j}
\equiv1\pmod {p^{3r}}.
```

Multiplying by the $p$-integral value $F(np^{r-1})$ proves (2).

This is the balanced-factorial form of the Laurent-product closure theorem
proved in
[Binomial-quotient cancellation](BinomialQuotientCancellation.md#1-laurent-binomial-products).

## 2. The recent A061164 direction

[OEIS A061164](https://oeis.org/A061164) is

```math
a(N)=\frac{(20N)!N!}{(10N)!(7N)!(4N)!}.
\tag{4}
```

The OEIS record identifies it as one of Vasyunin's sporadic integral
factorial ratios.  It also gives the especially short factorization

```math
a(N)=
\binom{20N}{10N}
\binom{10N}{3N}
\binom{4N}{N}^{-1}.
\tag{5}
```

Applying the closure theorem to (5) proves:

### Corollary

For every prime $p\geq5$ and all positive integers $n,r$,

```math
\boxed{
a(np^r)\equiv a(np^{r-1})\pmod {p^{3r}}.
}
\tag{6}
```

Thus, if Peter Bala's pending A061164 edit proposes the ordinary cubic
tower (6), that part is already closed by a classical scaling reduction.
The approved OEIS page viewed on July 31, 2026 did not yet display that
pending conjecture, so this note does not attribute wording that is not yet
public.

## 3. Bober's 52 sporadic ratios

The 52 integral factorial ratios A295431--A295482 in Bober's
classification are all balanced.  The closure theorem therefore gives,
simultaneously for every one of them,

```math
F(np^r)\equiv F(np^{r-1})\pmod {p^{3r}}
\qquad(p\geq5).
```

The record [OEIS A295431](https://oeis.org/A295431) cites Zudilin for the
prime-step case and records Bala's conjecture for the full tower.  The
all-level deduction, the complete 52-entry data audit, and the newer
fractional-index queue are recorded in the
[Bober sporadic packet](BoberSporadicFactorialRatioPacket.md).

## 4. What this does and does not settle

The theorem applies uniformly to every **balanced integral factorial
ratio**.  Fractional factorials are now covered by the companion
[rational gamma-ratio theorem](RationalGammaRatioCubicTowers.md).  When the
nonintegral slopes balance separately in every nonzero class modulo
$\mathbb Z$, their adjacent transfer is again cubic at primes away from the
fixed denominators.  Global integrality remains a separate obligation.

An extra factor $C^N$, a floor in a factorial argument, or a failure of the
residue-balance condition is not harmless and must still be audited
separately.

No assertion is made here for $p=2$ or $p=3$.  Those primes require the
separate denominator and sign analysis described in the repository's
[dyadic policy](../DYADIC_POLICY.md).
